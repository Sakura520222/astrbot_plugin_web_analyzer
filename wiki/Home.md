# 网页截图插件 Wiki

网页截图插件（内部 ID `astrbot_plugin_web_analyzer`）自动识别聊天中的网页链接并截图，支持命令和助手工具截图，可设置整页、视口、裁剪和加载等待方式；助手也可按需读取网页正文。

## 功能

- **自动识别链接**：聊天消息中出现网页链接时自动截图，支持单条和批量
- **手动命令**：`/网页截图 <URL...>`（`/网页分析` 为兼容别名）
- **助手工具**：`capture_webpage(urls)` 截图并发送原图；`get_webpage_content(url)` 按需读取正文
- **系统浏览器 CDP**：直接复用已安装的 Chrome / Edge / Chromium，不下载浏览器
- **截图参数**：视口尺寸、整页、JPEG/PNG、质量、加载等待方式、失败重试、裁剪
- **截图缓存**：按链接与截图参数命中缓存，支持有效期与条数上限（LRU）
- **访问规则**：允许 / 禁止域名列表、群聊黑名单
- **管理面板**：截图概览、截图缓存、访问规则、浏览器诊断四个页签，跟随宿主深浅主题
- **交互视图卡片**：新版 ChatUI 展示来源链接和缩略图，原图通过图片附件交付
- **代理与资源控制**：HTTP 代理（支持认证）、隐藏 IP、并发上限、浏览器实例上限、内存监控

## 版本要求

最低兼容 AstrBot **4.27.0**。交互视图卡片仅在宿主与平台支持时启用，否则回退为常规图片消息。
