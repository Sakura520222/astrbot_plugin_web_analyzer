# 配置指南

配置在 WebUI 的「插件管理 → 网页截图插件 → 配置」中维护；管理面板为只读展示。按五个分组组织。

## 触发与发送

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 自动识别链接 | 开 | 聊天中检测到链接时自动截图；关闭后仅响应命令 |
| 自动截图后继续交给会话模型 | 开 | 截图结果直接发送，消息继续交给本轮对话模型；关闭则截图后结束本轮 |
| 识别无协议头的链接 | 关 | 例如 `www.example.com` |
| 补全协议 | https | 无协议头链接使用的协议 |
| 群聊黑名单 | 空 | 每行一个群号；黑名单群聊不触发自动截图 |
| 发送提示消息 | 开 | 截图前发送「正在截图」提示 |
| 自动撤回提示 / 撤回时机 / 延迟 / 完成后立即撤回 | 开 / 完成后 / 10s / 开 | 提示消息撤回策略，依赖平台支持 |

## 截图

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 视口宽度 / 高度 | 1280 / 720 | 浏览器视口（320–4096 / 240–4096） |
| 截取整页 | 关 | 开启时截取整个页面；单张最多 1000 万像素 |
| 图片格式 / JPEG 质量 | JPEG / 80 | PNG 无损；质量仅对 JPEG 生效 |
| 加载等待方式 / 等待时间 | 固定等待 / 2000ms | 可选「等待网络空闲」「网络空闲后短暂等待」 |
| 失败重试次数 | 1 | 仅浏览器实例故障时更换实例重试；页面加载失败或内容超限不重试 |
| 启用裁剪 / 裁剪坐标 | 关 / [0,0,1280,720] | 只保留指定矩形区域 |

## 访问规则

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 允许的域名 | 空 | 每行一个；留空允许所有未被禁止的域名 |
| 禁止的域名 | 空 | 每行一个；优先级高于允许列表 |
| 合并 www 域名 | 关 | `example.com` 与 `www.example.com` 归一（影响缓存与去重） |
| 允许访问本地与内网地址 | 关 | 开启后可截图或读取 `127.0.0.1`、`192.168.x.x`、`localhost` 等本地/内网地址；仅建议在可信网络环境开启 |

域名匹配支持子域名后缀匹配。链接中的内网 / 回环 IP 与 `localhost` 域名默认一律拒绝（SSRF 防护）；命令、自动识别与助手工具共用同一套规则。

## 缓存

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用缓存 | 开 | 相同链接 + 相同截图参数直接复用已有截图 |
| 有效期（分钟） | 1440 | 5–10080 |
| 缓存条数上限 | 100 | 超出按最久未使用淘汰 |

## 浏览器与网络（高级，默认折叠）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 正文抓取方式 | HTTP 请求 | 需要 JavaScript 渲染的页面可选「系统浏览器」 |
| 正文长度上限 | 10000 字符 | `get_webpage_content` 返回正文的上限 |
| 处理超时 | 30 秒 | 导航与请求上限 |
| 请求重试次数 / 间隔 | 3 / 2s | HTTP 正文抓取的重试 |
| 并发上限 | 5 | 批量截图同时处理的链接数 |
| User-Agent | 空 | 留空使用默认值 |
| HTTP 代理 | 空 | 格式 `http://用户名:密码@主机:端口`；配置文件明文保存 |
| 截图使用代理并限制 WebRTC | 关 | 需先配置代理；不能保证匿名 |
| 沙箱模式 | 自动检测 | 容器环境自动禁用沙箱 |
| 最大实例数 | 3 | 启动中 + 使用中 + 空闲浏览器进程总量上限 |
| 启用内存监控 / 阈值 | 关 / 80% | 超阈值执行垃圾回收并缩减实例池 |

## v1.x → v2.0.0 迁移

首次加载自动迁移：代理、User-Agent、截图尺寸与等待、访问规则、缓存限制按旧值写入新配置。旧 `analysis_mode=manual`、`send_content_type=analysis_only` 或截图关闭时，迁移后「自动识别链接」关闭。旧分析 / 翻译 / 模板 / 提取 / 合并转发配置不再使用。
